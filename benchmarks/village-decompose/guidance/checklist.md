# Decomposition checklist

Work through the contract's mechanical requirements in order, checking each
before finishing:

1. Read the misfit texts and note the recurring concerns: livestock, water,
   crops, land, health, education, social standing, infrastructure, credit and
   administration are candidate centers.
2. Draft groups around those centers. Aim for the middle of the allowed
   8-to-16 group range.
3. Place every misfit ID exactly once. Keep linked pairs inside one group
   where the group sizes allow it.
4. Give every group a nonempty name describing its shared concern, and at
   least two member misfits.
5. Recount: every ID `m1`–`m141` present exactly once; group count inside the
   bounds; no singleton or unnamed group.

Return only the closed JSON artifact. Do not return calculations, explanations
or additional fields.
